# 2D Shooting Game

Simple browser-based 2D shooting game built with HTML5 Canvas.

## Run

Open `/home/runner/work/skills-copilot-codespaces-vscode/skills-copilot-codespaces-vscode/index.html` in a browser.

## Controls

- **Move:** `←` / `→` or `A` / `D`
- **Shoot:** `Space`
- **Restart:** `R` (after game over)
